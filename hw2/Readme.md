
## Сборка и запуск



```bash
c++ -std=c++17 -Wall -Wextra main.cpp Inventory.cpp Transport.cpp Things.cpp ServiceCenter.cpp Fleet.cpp -o fleet
./fleet
```

После запуска вводите команды по одной на строку.
Команда `quit` завершает программу. Завершение ввода также завершает работу.


## Команды

| Команда                            | Назначение                                                        |
|------------------------------------|-------------------------------------------------------------------|
| `help`                             | Показать список команд и аргументы                                |
| `add scooter id name energy score` | Добавить электросамокат                                           |
| `add bike id name score`           | Добавить велосипед                                                |
| `add ebike id name energy score`   | Добавить электровелосипед                                         |
| `add cargo id name score capacity` | Добавить грузовой велосипед                                       |
| `add helmet id name`               | Добавить шлем                                                     |
| `add dock id name energy`          | Добавить док-станцию                                              |
| `list`                             | Вывести все позиции по возрастанию инвентарного номера            |
| `count`                            | Вывести количество позиций                                        |
| `energy`                           | Вывести суммарный суточный расход энергии                         |
| `novice`                           | Вывести транспорт с оценкой простоты не ниже текущего порога      |
| `can_carry weight`                 | Вывести транспорт, способный перевезти указанный вес              |
| `set_novice_minimum value`         | Изменить порог для новичков: целое число от 1 до 10, изначально 6 |
| `focus id`                         | Выбрать позицию для витрины                                       |
| `show_focus`                       | Показать выбранную позицию или `expired`                          |
| `remove id`                        | Удалить позицию по номеру                                         |
| `quit`                             | Завершить программу                                               |

Номера и названия вводятся без пробелов. Команды и обозначения типов
нужно вводить строчными буквами.

Ограничения:

- Инвентарные номера уникальны.
- Вместимость парка — 100 позиций.
- Простота управления — целое число от 1 до 10.
- Расход энергии — конечное неотрицательное число, кВт·ч в сутки.
- Грузоподъёмность и запрашиваемый вес — конечные положительные числа в кг.

`energy` печатает число с одним знаком после точки.
`novice` и `can_carry` выводят позиции в порядке добавления.
Если подходящих позиций нет, список пуст.


## Техосмотр


Если название транспорта содержит `broken` без учёта регистра
английских букв, выбрасывается `InspectionRejected`.


## Наследование и полиморфизм

Основная иерархия:

```text
InventoryItem
├── Transport
│   ├── Bike
│   ├── CargoBike
│   ├── Scooter
│   └── ElectricBike
├── Helmet
└── Dock
```

Дополнительный базовый класс:

```text
EnergyConsumer
├── Scooter
├── ElectricBike
└── Dock
```

`InventoryItem` и `EnergyConsumer` — абстрактные классы
с виртуальными деструкторами.

Множественное наследование используется в `Scooter`, `ElectricBike`
и `Dock`: каждый из них одновременно является имуществом
и потребителем энергии.

## Умные указатели


- `unique_ptr<InventoryItem>` создаётся в `add_function()` в `main.cpp`
  и передаётся в `Fleet::add()`. До успешного техосмотра он единолично
  владеет новым объектом. 
- После проверки владение передаётся в `shared_ptr<InventoryItem>`.
  Принятые позиции хранятся в `Registry`, внутри которого находится `vector`.
- `weak_ptr<InventoryItem> focus_` хранит выбор витрины. Для показа используется `lock()`.

После удаления выбранной позиции из парка, если других владельцев нет,
`show_focus` выводит `expired`.

## Шаблоны

В `Registry.hpp` реализован `Registry<T, Cap>`:

- `T` — тип элемента;
- `Cap` — максимальное количество элементов которое вмещает парк.

Класс предоставляет `add`, `size`, `operator[]` и `remove`.
Оператор `<<` копирует элементы во временный `vector`, сортирует
и печатает их, не меняя порядок хранения в исходном реестре.

В `Fleet` используется:

```cpp
Registry<shared_ptr<InventoryItem>, 100>
```

Функции `print_registry_value` и `registry_less` имеют явные
специализации для `shared_ptr<InventoryItem>`.

## Операторы

В `Inventory.cpp` реализованы:

- `operator<<` — вывод инвентарного номера и имени;
- `operator<` — лексикографическое сравнение номеров;
- `operator==` — сравнение позиций по совпадению номера.

Дополнительным оператором выбран `==`.
Имена и другие характеристики в этом сравнении не учитываются.

## Исключения

Все собственные ошибки объявлены в `Errors.hpp`.

```text
std::exception
└── std::runtime_error
    └── FleetError
        ├── InvalidArgument
        ├── InspectionRejected
        └── RegistryFull
```

- `InvalidArgument` — неправильные аргументы, неизвестные команды,
  повторный номер, отсутствующая позиция или неверный индекс.
- `InspectionRejected` — отказ техосмотра.
- `RegistryFull` — превышение вместимости реестра.

Операции выбрасывают исключения. Сообщения печатаются в `catch`
в `main()` с префиксом `error:`.


## Креативная часть

Добавлен `CargoBike` — грузовой велосипед без двигателя
с собственной грузоподъёмностью.

Команда добавления:

```text
add cargo C-1 HeavyBike 7 80
```

Дополнительная команда:

```text
can_carry 40
```

Она выбирает транспорт с грузоподъёмностью не меньше 40 кг.
Используется виртуальный `cargo_capacity()`, поэтому команда
не зависит от конкретного класса `CargoBike`.

Обычный транспорт возвращает грузоподъёмность 0.
